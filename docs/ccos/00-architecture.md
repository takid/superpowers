# 00 — Organisational Architecture

## What it owns

The shape of the company. Which functions exist, who holds them, how decisions get
made, and the meeting rhythm that keeps the whole thing honest.

This module owns nothing operational. It owns the container everything else runs in.

## The rule that makes this work

Create the position before you can afford the person.

Every function below exists from today. Most of them are held by Taka or by software
or by Claudia. That is fine. What is not fine is leaving a function undefined, because
undefined work does not get done, it gets absorbed, and absorbed work is invisible
until it fails.

Write the role. Name the holder. When revenue allows, hire into a role that already
has a definition, a checklist, and a number attached to it. That is a two week
handover instead of a six month one.

```
        |                       |                       |
   +----+----+           +------+------+          +-----+-----+
   |         |           |             |          |           |
Marketing  Sales     Scheduling     Quality    Accounts     KPIs
   |         |           |             |          |           |
   |         |           +------+------+          +-----+-----+
   |         |                  |                       |
   +----+----+             Team Leaders                 |
        |                       |                       |
        |                   Cleaners                    |
        |                       |                       |
        +-----------> CUSTOMERS <+----------------------+
```

Cleaners sit under Team Leaders, not under the CEO. That single line is the difference
between a business and a job. The moment a cleaner's default escalation route is the
CEO's mobile, the CEO is the operations manager and always will be.

## The seven functions

Each function has an owner, a primary number, and a module that defines its work.

| Function | Owns the decision | Primary number | Defined in |
|----------|-------------------|----------------|------------|
| Marketing | Where leads come from, what we say, brand standards | Cost per qualified lead | 01 Sales OS |
| Sales | Whether we take the job and at what price | Quote to booking conversion | 01 Sales OS |
| Scheduling | Who goes where, when, and in what order | Utilisation, on-time rate | 02 Operations OS |
| Quality | Whether the work met standard | CC Quality Score | 02 Operations OS |
| People | Who cleans for us and how good they are | Certified cleaner count, 90 day retention | 03 Cleaner OS |
| Customer | Whether they come back | Recurring conversion, churn | 04 Customer OS |
| Finance | What we charge and what we keep | Gross margin, recurring revenue | 05 Finance OS |

If a decision does not have an obvious home in this table, it belongs to the CEO by
default. Add it to the table the second time it comes up. The third time you make the
same judgement call by instinct, it should already be a written rule.

end up carrying overhead through a quiet January. Hiring on a trigger you set in
advance, while calm, is how you stay solvent.

## Decision rights

Three tiers. Everyone should know which tier they are standing in.

**Tier 1, decide and proceed.** No approval needed. Anyone holding the function decides.
Examples: reordering a route for traffic, swapping a cleaner between two same-day jobs,
applying a goodwill re-clean under £60, answering a standard enquiry with grid pricing.

**Tier 2, decide and report.** Act now, log it, report at the weekly. Examples: refund
up to £150, accepting a job at up to 10% below grid price, agreeing an out-of-area job
inside the extended radius, releasing a cleaner from a shift.

**Tier 3, CEO only.** Pricing changes to the grid. Any contract above £1,000 per month.
Hiring. Dismissal. Anything creating a liability beyond 30 days. Anything involving
insurance, regulators, or a solicitor. Discounting below the margin floor in 05.

The point of Tier 1 is speed. The point of Tier 3 is that a bad decision there can end
the company. Most small businesses invert this and approve the small things while
improvising the large ones.

## Operating cadence

The rhythm is the system. Without it, CCOS is a document nobody opens.

**Daily, 15 minutes, morning.**
Today's jobs confirmed and staffed. Yesterday's exceptions cleared. New leads from
overnight responded to. Run from the Claudia daily brief (see 06). Fifteen minutes,
standing up, no discussion of anything that is not today.

**Weekly, 45 minutes, same slot every week.**
Seven numbers, in this order: leads, quotes sent, bookings, recurring conversions,
quality scores below 80, complaints open, cash in. Then the exceptions log from the
week. Then one decision. One. A weekly meeting that produces no decision is a report,
and a report should have been an email.

**Monthly, 2 hours.**
Full P&L against plan. Margin by service line. Cleaner performance review. Customer
churn and win-back. Marketing channel cost per acquisition. Then set the single
constraint for the coming month, the one thing most limiting growth, and name who owns
removing it.

**Quarterly, half a day, out of the building.**
Strategy. Pricing review. Capacity plan for the next quarter. Review every module of
CCOS and mark each one green, amber, or red on whether it is actually running or just
written down. Amber and red get an owner and a date.

## The CEO's job

The job changes as the modules come online. Written plainly so the drift is visible.

**Today.** Selling, quoting, scheduling, problem solving, quality checking, and
building CCOS itself. Building CCOS is the part that has to be protected. Block it in
the diary and treat it like a client appointment, because it is the only work here that
compounds.

**At Phase 3 complete.** Marketing direction, pricing, key accounts, recruitment,
managing the ops holder, reading the numbers.

**Target.** Strategy, capital, people, growth, partnerships, brand, systems, numbers.
Nothing on that list is a job that arrives by phone at eight in the morning.

The measurable version of this: track the percentage of the week spent on work only
the CEO can do. If it is below 40%, the next module to build is whichever one is
generating the interruptions.

## The records

- **Function table** with current holders. Reviewed monthly, updated on change.
- **Decision log.** Every Tier 2 and Tier 3 decision, one line, date, who, what, why.
  This becomes the training material for the person who eventually holds the function.
- **Exceptions log.** Anything that did not go to plan. Feeds the weekly.
- **Constraint of the month.** One line. Visible. Reviewed at the next monthly.

## Definition of done

- [ ] Every one of the seven functions has a named holder, even if the name is Taka or Claudia
- [ ] Every function has one primary number and someone can state it from memory
- [ ] Hiring triggers are written down with a threshold, not a feeling
- [ ] Daily, weekly, monthly, quarterly meetings exist in the calendar as recurring slots
- [ ] Decision log has been running for four consecutive weeks
- [ ] Cleaners escalate to a Team Leader, not to the CEO, and know it
