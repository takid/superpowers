# Coventry Cleans memory pack

Built 2026-10-10 from past Claude sessions, Google Drive, and Taka's standing instructions.

## Load into Cowork
1. Copy this whole folder into the Cowork working folder (the one Cowork opens as its project).
2. Cowork reads `CLAUDE.md` first. It points to `memory/` for detail.
3. Check "Open loops" and "Right now" first. Those go stale fastest.

## Keep it current
Re-run the sync after any big build session. Edit `CLAUDE.md` first, then the matching file in `memory/`. Keep `CLAUDE.md` short.

## Left out on purpose
Customer names and contact details, bank details, accounts and financial figures, API keys and credentials. Pull those live from the source system when needed.

## Caveats
- Session facts come from session summaries. 15 sessions had no summary and one (operating system redesign, highest cost) returned no readable events. Treat gaps there as unknown.
- 35 of an older, longer session list were read. Earlier sessions are not covered.
- Drive trackers mostly hold sample rows, so figures in them are not business results.
